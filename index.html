Proof, not claims

 
A sample of my report format, and the kind of bug behind it.

 

  

   
HIGHSQL injection on POST /login

   
Impact
An attacker signs in as any user without a password.
Evidence
The payload in the login field returned every user row and a valid session.
Fix
Use parameterized queries. Treat input as data, never as SQL.

   
Illustrative example, not a client finding.
